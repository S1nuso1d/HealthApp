# Play Console — Data safety и обоснования разрешений

Заполните форму Data safety в Play Console по этому чеклисту. Тексты можно копировать.

## Категории данных

| Данные | Собираем | Передаём | Цель |
|--------|----------|----------|------|
| Email / пароль | Да | На наш сервер | Аккаунт |
| Здоровье (сон, шаги, пульс, питание) | Да | На наш сервер | Дневник и синхронизация |
| Фото | Да (по действию пользователя) | На наш сервер | Еда / обложка тренировки |
| Геолокация | Да (только во время живой тренировки) | Может уходить на сервер в метаданных тренировки | Трек пробежки |
| Приблизительное устройство / crash | Да (если включён Sentry DSN) | Sentry | Стабильность |

## Разрешения Android

| Permission | Зачем пользователю |
|-----------|-------------------|
| POST_NOTIFICATIONS | Напоминания о воде, еде, таблетках |
| CAMERA | Фото еды, штрихкод, обложка тренировки |
| ACCESS_FINE/COARSE_LOCATION | GPS-трек живой пробежки |
| ACTIVITY_RECOGNITION | Шаги / активность |
| BLUETOOTH_* | Опциональный Mi Band |
| RECORD_AUDIO | Опциональный анализ звука сна |
| SCHEDULE_EXACT_ALARM | Точные напоминания о таблетках |
| Health Connect READ_* | Импорт сна, шагов, пульса с согласия |

## Health Connect

В rationale activity и на экране конфиденциальности указано: данные читаются только после согласия и для отображения/синхронизации в дневнике HealthApp. Ссылка на политику: `PRIVACY_POLICY_URL` из `local.properties`.

## Перед релизом

1. Выложить `docs/legal/privacy.html` и `terms.html` на HTTPS.
2. Прописать URL в `local.properties` (`PRIVACY_POLICY_URL`, `TERMS_OF_SERVICE_URL`).
3. Задать `PROD_API_BASE_URL=https://…/`
4. Создать `keystore.properties` + upload key.
5. Добавить `SENTRY_DSN=…` для crash reporting.
